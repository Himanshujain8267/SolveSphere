# SolveSphere — ML Pipeline

Placement readiness and package prediction pipeline for SolveSphere.

---

## Quick Start

```bash
cd ML

# 1. Install dependencies
pip install -r requirements.txt

# 2. Generate synthetic data (runs immediately, no download needed)
python src/00_generate_synthetic_data.py

# 3. Run the full pipeline in order
python src/01_load_data.py
python src/02_clean_data.py
python src/03_eda.py
python src/04_feature_engineering.py
python src/05_split_data.py
python src/06_preprocessing.py
```

EDA plots are saved to `reports/eda/`.

## Dataset Schema

| Column | Type | Description |
|---|---|---|
| `student_id` | string | Unique identifier — dropped before training |
| `age` | int | Student age |
| `gender` | categorical | Male / Female |
| `branch` | categorical | CSE, IT, ECE, EEE, MECH, CIVIL |
| `cgpa` | float | 0–10 |
| `projects` | int | Number of projects |
| `internships` | int | Number of internships |
| `skills_count` | int | Number of skills listed |
| `leetcode_solved` | int | Problems solved on LeetCode |
| `leetcode_rating` | float | LeetCode rating (NaN if no account) |
| `leetcode_contest_rating` | float | LeetCode contest rating |
| `codeforces_rating` | float | Codeforces rating |
| `codeforces_solved` | int | Problems solved on Codeforces |
| `codechef_rating` | float | CodeChef rating |
| `codechef_solved` | int | Problems solved on CodeChef |
| `github_repos` | int | Number of GitHub repositories |
| `github_contributions` | int | GitHub contributions (annual) |
| `github_stars` | int | Total GitHub stars received |
| `placed` | int (0/1) | Placement outcome |
| `package_lpa` | float | Package offered in LPA (NaN if not placed) |

---

## Engineered Features (added in Step 4)

| Feature | Formula |
|---|---|
| `total_problems_solved` | LC + CF + CC solved |
| `platforms_connected` | Count of non-null ratings |
| `highest_rating` | max(LC, CF, CC ratings) |
| `average_rating` | mean(LC, CF, CC ratings) |
| `coding_activity_score` | GitHub contributions + total solved |
| `cp_score` | Weighted composite (CF 40%, LC 35%, CC 25%), normalized 0–1 |
| `profile_completeness` | Fraction of optional platform fields filled |

## Data Sources

### Phase 1 (current): Synthetic data
- `00_generate_synthetic_data.py` creates 500 realistic students
- Features are correlated via a hidden "talent" score
- Use this to build and validate the entire pipeline

### Phase 2: Kaggle baseline
Download: [Campus Recruitment Dataset](https://www.kaggle.com/datasets/benroshan/factors-affecting-campus-placement)
- Place in `data/external/`
- Map columns to the schema above
- Lacks coding platform data — supplement with engineered features

### Phase 3: Real data via Google Form
Collect from college communities with:
- CGPA, branch, projects, internships
- Platform usernames → auto-enrich via APIs
- Self-reported placement outcome + package

### Phase 4 (production): SolveSphere users
- Users who connect their profiles → feature extraction via APIs
- Opt-in placement outcome sharing → grows training set automatically
- Retrain model periodically
